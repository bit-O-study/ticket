- 화면 검토: test-results/dashboard.png (Git 제외).
- 발견/수정: 탭 생성 직후 Chrome의 중간 오류 화면을 최종 실패로 오인하던 경로를 수정. 같은 탭의 로딩 완료 후 감시 연결만 재시도하며, 새로고침이나 추가 탭 생성은 하지 않는다. 최대 60초 뒤 직접 확인 상태로 전환.
- 외부 요청은 테스트에서 모두 가상 HTML로 대체. 실제 예매·좌석 점유·로그인·결제는 하지 않았다. 운영 예매처별 DOM 호환성, 실제 OS 알림 표시, 사용자의 브라우저 절전/재시작 환경은 추가 확인 필요.
- 알림/예매 버튼 1회 클릭까지 구현. 좌석 자동 선택과 결제 자동화는 미구현.

## 0.2.0 · 실제 동작 매크로 (2026-10-06)

- 단위 테스트 12개 및 JavaScript 문법 검사 통과.
- Chromium 확장 통합 8개 검사 항목 통과: 실제 클릭 없는 대상 지정, 경기→구역→인원 2명→빈 좌석 2개→좌석 선택 완료, 4개 화면 폭, 인증 중지/재개, 대기 중 즉시 중지, 제한 시간 초과, 예매 팝업+좌석 iframe, 결제 화면 차단. 실제 예매 요청 없는 가상 화면.
- Edge 별도 DOM 검사 5개 통과: 연속 좌석 부족 시 부분 선택 없음, 비활성/판매 좌석 제외, 연속 두 좌석 선택, 다른 열을 연석으로 간주하지 않음, 연석 해제 모드의 명시적 선택.
- 추가한 알람 시각 실행·편집기 재로딩 통합 시나리오는 재실행 과정에서 환경 제약으로 미확인. Windows가 Chrome for Testing의 GPU/네트워크 프로세스를 접근 거부(error 63/0x5)하여 종료. 권한 상승으로도 동일. 일반 Edge는 명령줄 확장 로드를 하지 않아 통합 검사 대체 불가. 단위/DOM 검사로 대체 범위를 구분했고 전체 통합 재통과로 표시하지 않음.
- 공개 페이지 읽기 전용 확인: 티켓링크 스포츠 페이지의 구단 링크는 확인, NOL은 서비스 제한 화면. 로그인 이후 실제 좌석 흐름은 미검증.
- 자료: tests/macro.browser.mjs, tests/macro-dom.browser.mjs, tests/macro-core.test.mjs. 스크린샷 test-results/macro.png는 Git 제외.

## 0.3.0 · 취소표 대기 (2026-10-06)

- Node 테스트 18개 통과. Chrome API 모의 실행으로 갱신 후 반환 좌석 선택 1회, 알림 모드 클릭 없음, 중지 이후 갱신/선택 없음, 최대 대기 시간 만료를 검증.
- Edge DOM 테스트 7개 통과. 기존 좌석 선택 검사에 매진→빈 좌석 전환, 비활성 매진 좌석의 구역 지정 및 실제 클릭 방지를 추가.
- JavaScript 문법 검사 통과. 실제 예매 요청/좌석 점유/결제 없음. 실제 예매처별 취소표 확보, OS 알림 표시 및 확장 전체 통합은 이번 검증에 포함하지 않음.
- 갱신 버튼을 지정하지 않으면 DOM 변경만 감지하며 서버에서 좌석을 별도로 조회하지 않음.

- `npm test`: 66개 단위 테스트 통과(Node 20.16). 추가: manifest 권한·허용 호스트 일치, tabs 권한 없음, 공통 인원 상한, KST 연도 표시(자정 24시 표기 버그 수정), URL 세션 쿼리 제거, 준비 알림 건너뛰기(가짜 시계), 백업 지난 경기 제외·100건 초과, validatePlan null 입력, 결제 컨트롤 감지(가짜 DOM: input value/alt, img alt, 부분 일치, 비활성 포함), 대상 지정 모드 해제(전송 실패·예외·Esc), 서비스 워커 재시작 시 매크로 일시 중지·sweep 알람 재생성·MACRO_PICK_STOP, 메시지 type 가드, MACRO_ 전달, 알림 클릭 화면 분기, runToken, STOP_ALL, 수정·재시작·백업 흐름.
- `npm run check`: 전체 src 문법 검사 통과.
