# 첫 공 · KBO 티켓 도우미 / 티켓팅 매크로 (0.4.0)

> **⚠️ 사용 전 반드시 읽어 주세요**
>
> - 티켓링크·NOL 티켓(인터파크)·구단 전용 예매처 등 대부분의 예매 사이트 **이용약관은 매크로·자동화 프로그램 사용을 금지**합니다. 위반 시 예매 취소, 계정 이용 제한 등 불이익이 생길 수 있고, 관련 법령 위반 소지가 있을 수 있습니다.
> - 이 확장 프로그램의 **자동 클릭(매크로)·좌석 갱신 반복 기능을 사용할지와 그 결과에 대한 책임은 전적으로 사용자에게 있습니다.** 사용 전에 이용하는 예매처의 약관을 직접 확인하세요.
> - 예매 오픈 시간 알림·예매처 열기만 사용하고 자동 클릭 옵션을 끄면 사이트 화면을 자동으로 조작하지 않습니다.

Chrome/Edge 확장 프로그램(Manifest V3)입니다. 서버·계정·API 키 없이 브라우저 안에서만 동작하며 데이터는 이 브라우저 프로필의 `chrome.storage.local`에만 저장합니다.

## 이 확장 프로그램이 하는 일

### 1. 오픈 예약 도우미 (dashboard.html)
- 홈 구단·상대·경기 시각·예매 오픈 시각(한국 시간)을 등록하면, 오픈 시각에 예매 페이지 탭을 **한 번** 엽니다. 오픈 N분 전 준비 알림(끄기/1/3/5/10/30분)을 보냅니다. 알림 시각이 이미 지났거나 1분 넘게 늦으면 보내지 않습니다.
- 열린 탭의 **현재 화면 DOM을 1.5초 간격으로 확인**해 날짜·시간·양 팀이 일치하는 예매 버튼이 하나뿐이면 알림을 보냅니다. 이 단계는 새로고침이나 서버 요청을 반복하지 않습니다(1~10분 제한).
- 선택 옵션(기본 꺼짐) **"예매 버튼을 한 번 클릭"** 을 켜면 그 버튼을 1회 클릭합니다. 로그인·대기열·보안문자·결제 화면이 보이면 멈추고 직접 진행하도록 안내합니다.
- 예약 수정·복제·재시작(재시작/복원한 예약은 자동 클릭 꺼짐), 전체 중지, 백업 저장/불러오기(예정 경기만, 최대 100건, 실행 기록·탭·토큰·주소의 세션성 쿼리 값 제외).

### 2. 티켓팅 매크로 (macro.html, 확장 아이콘을 누르면 열림)
- 사용자가 예매 화면에서 직접 지정한 대상(글자가 있는 버튼, 인원 선택 목록, 빈 좌석 구역)을 **순서대로 자동 클릭/선택**합니다. 대상이 나타날 때까지 단계별로 3~120초 기다립니다(약 0.6초 간격 화면 확인).
- 빈 좌석 단계에서 **취소표 대기**를 켜면 최대 120분 동안 지정 구역을 확인합니다. **좌석 갱신 버튼을 지정하면 확인 간격(5~120초)마다 그 버튼을 눌러 예매처 서버에 반복 요청을 보냅니다.** 갱신 버튼을 지정하지 않으면 현재 화면의 변경만 감지합니다.
- 실행 예약: 지정한 한국 시각에 Chrome 알람으로 매크로를 시작합니다.

### 안전 장치
- **결제 단계 자동 정지(fail closed):** 화면에 결제 관련 컨트롤(버튼·링크·`<input type=submit|button|image>`의 값/alt, `<img alt>`)이 하나라도 보이면 — 비활성 상태여도 — '결제'·'구매 확정'·'예약 확정'·'pay now'·'checkout' 등을 **부분 일치**로 감지해 매크로를 멈춥니다. 결제 문구가 있는 버튼이나 글자가 없는 버튼은 클릭 대상으로 저장할 수 없습니다.
- 로그인·보안문자·대기열이 보이면 멈춥니다. 우회하지 않습니다. 자동 결제는 구현하지 않습니다.
- 실행 결과가 불확실한 단계는 자동 재실행하지 않고 사용자가 확인 후 "넘기기"를 선택해야 합니다.
- 브라우저 또는 확장 서비스 워커가 다시 시작되면 실행 중이던 매크로는 **일시 중지** 상태로 바뀝니다(자동 재개 안 함).
- 대상 지정 모드는 Esc·지정 완료·오류·확장 재시작 시 항상 해제되어 실제 클릭을 가로채지 않습니다.
- 접근 사이트는 `manifest.json`의 `host_permissions`와 코드의 허용 목록(`src/core.js`의 `HOST_PERMISSIONS`)이 정확히 일치하며 테스트로 검증합니다. `tabs` 권한은 사용하지 않습니다.

## 설치 / 업데이트
1. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**에서 이 폴더(`C:\git\Bit-O\ticket`, manifest.json이 있는 폴더)를 선택합니다.
3. 이미 설치했다면 **새로고침**을 누릅니다. 0.4.0에서 `tabs` 권한을 제거하고 인터파크 권한을 티켓 하위 도메인으로 좁혔습니다.

## 매크로 사용 순서
1. 홈 구단을 고르고 예매처를 엽니다. 로그인·본인인증은 직접 처리합니다.
2. **열린 탭 다시 찾기**로 대상 예매 탭을 선택하고, **클릭할 버튼 지정** 등을 누른 뒤 예매 화면에서 대상을 찍습니다(지정 중에는 실제 클릭이 실행되지 않음, Esc로 취소).
3. 동작 순서·대기 시간을 정리하고 **매크로 실행**을 누릅니다.
4. 인증·대기열에서 멈추면 직접 처리한 뒤 **멈춘 단계 재개** 또는 **직접 처리한 단계 넘기기**를 누릅니다. 결제는 직접 확인합니다. 동작 완료는 예매 성공이나 좌석 확보를 뜻하지 않습니다.

## 한계
- 구단별 완성된 예매 시나리오는 없습니다. URL·버튼 문구·DOM이 바뀌면 다시 지정해야 합니다.
- 빈 좌석 선택은 열·번호가 DOM 속성/텍스트에 있는 좌석만 지원합니다. Canvas/이미지 좌석도는 미지원입니다.
- 결제 문구 부분 일치는 안내 문구가 있는 링크(예: "결제수단 안내")에도 반응해 매크로를 멈출 수 있습니다. 의도된 보수적 동작입니다.
- 실제 로그인 이후 각 예매처 화면은 검증하지 않았습니다. NOL 티켓의 인터파크 하위 도메인(`ticket`, `tickets`, `poticket`)은 실서비스로 확인하지 않았습니다(docs/SOURCES.md).
- PC·브라우저가 켜져 있어야 하며 절전·브라우저 정책으로 알람이 늦을 수 있습니다. 1분 넘게 늦은 예약은 실행하지 않습니다.

## 검증
- Node 20 이상: `npm test`(단위 테스트, Chrome API 모의), `npm run check`(문법 검사).
- 브라우저 통합 테스트: `npm install` 후 `npx playwright install chromium msedge`, `npm run test:browser`. 이미 설치된 Playwright가 있으면 `PLAYWRIGHT_MODULE`에 `playwright/index.mjs` 경로를 지정합니다. 테스트의 HTTP(S) 요청은 모두 가상 HTML로 대체되어 실제 예매 사이트에 접속하지 않습니다.

## 파일
- `src/core.js`: 구단/예매처/허용 호스트, 인원 상한, 한국 시간, 예약·백업 검증, URL 정리
- `src/background.js`: 오픈 예약·알람·알림 상태 관리(매크로 메시지는 macro-engine으로 전달)
- `src/content.js`: 오픈 예약 탭의 경기 카드 확인·1회 클릭
- `src/dashboard.js`, `dashboard.html`: 오픈 예약 화면
- `src/macro-*.js`, `macro.html`: 매크로 지정·실행
- `docs/`: 확인 기록, 검증 기록, 이전 폴더 안내
